# Grok Command Watch 方案（讨论稿 · 2026-08-17）

硬件：M5Stack StopWatch C152（已插 `/dev/cu.usbmodem2301`）  
宿主：Ghostty + Grok Build（无 Codex Desktop）  
仓库参考：`codex-micro-stopwatch` 只借板级/BLE/电源，不借 Codex HID 和额度环。

## 你的工作单元

- **Command N** = Ghostty 第 N 个标签（⌘1–⌘4）。当天至少 1 个，最多常用到 4。
- 每个 Command 里 **1 或 2 个分屏**（⌘D）。
- 表要一眼看到：哪个 Command 活着、在忙、在等你、出错了。
- 另外要语音输入。

## 不做什么

- 不刷上游「Codex Micro」固件当成品。它只认 ChatGPT Desktop。
- 不把对话全文、token、路径写上手表。
- 第一期不从手表点「批准工具」。
- 第一期不用表上的 USB 麦（本机已有 DJI 接收器；Grok 语音走终端麦）。

## 产品形状

表 = **四个 Command 扇区**，有分屏的扇区再切成左右两块。空 Command 留位但不亮。

状态色：

| 色 | 意思 |
|---|---|
| 暗 | 这个 Command 今天没开 |
| 灰 | 开着，闲 |
| 青 | 正在跑 |
| 黄 | 要你（权限 / 提问 / 停住） |
| 绿闪一下 | 刚做完 |
| 红 | 失败 / 断线 |

圆心：当前选中格的短标题（用 Grok 的 `last_turn_summary`），下面一行状态字。  
前台那一格加细环。

## 数据从哪来

Ghostty 没有「这个 grok 在 ⌘2 左分屏」的现成接口。

推荐绑定：

1. 启动用薄包装：`g1` / `g1r` / `g2` / `g2r` … 在对应标签的对应分屏里开 `grok`，并写下 slot。
2. Grok hooks 写本机 roster（`UserPromptSubmit` 忙；`Stop`/`StopFailure`/`StopCancelled` 结；`Notification` 的 `permission_prompt` / `idle_prompt` 补）。
3. Mac companion 读 roster + `~/.grok/active_sessions.json` + 该 session 的 `summary.json`，经 BLE GATT 推表。
4. 表不存账号。

## 按键（C152）

| 手势 | 作用 |
|---|---|
| 点某个格 | 选中；再点一次 → 本机切到那个 Ghostty 标签/分屏 |
| 左右滑 | 换 Command 1–4 |
| 按住左实体键 | PTT：对选中格语音（走 Mac/DJI 麦，companion 转写后打进该 Grok） |
| 点右实体键 | 跳到「最需要你」的那一格并前置 Ghostty |
| 点圆心 | 只前置，不发送、不批准 |
| 红键 | 休眠 / 旅行关机（沿用板级电源） |

## 分期

1. hooks + roster + companion + 表显示/震动（先能看）
2. 点表切 Ghostty
3. 左键 PTT 语音进选中 Grok
4. 以后再说：表上答权限、USB 麦、一个标签里两个以上分屏
